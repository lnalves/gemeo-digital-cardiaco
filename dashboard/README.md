# dashboard/

Front-end próprio (React + Vite + TypeScript + uPlot). Criado na fase F6:

```bash
npm create vite@latest . -- --template react-ts
npm install uplot
npm run dev   # http://localhost:5173
```

Telas, mensagens WebSocket e requisitos: `docs/ARQUITETURA.md` §9–10. Textos da interface em português;
aviso "ferramenta de apoio à decisão" sempre visível (RNF07).
